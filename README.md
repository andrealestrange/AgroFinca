# AGROFINCA

Sitio web de una empresa que vende productos para el cuidado de animales y cultivos en Sahagún, Córdoba. Proyecto de Desarrollo Web, Ingeniería de Sistemas, Universidad de Córdoba.

**Autora:** Andrea Carolina Flórez Suarez
**Docente:** Jose David Díaz Zurita

**Estado:** Primera entrega (HTML5 semántico y diseño responsive). Siguen JavaScript con APIs y localStorage (Avance 2) y Vue.js (entrega final).

**Ver el sitio:** https://andrealestrange.github.io/agrofinca/

## Páginas

- `index.html`: inicio, con servicios y presentación de la empresa
- `productos.html`: catálogo de productos
- `detalle-producto.html`: información de un producto
- `carrito.html`: productos elegidos y total
- `login.html`: inicio de sesión
- `registro.html`: crear una cuenta

## Lo que se usó

- HTML5 semántico: `header`, `nav`, `main`, `section`, `article`, `aside` y `footer`.
- Formularios con validación nativa: `required`, `pattern`, `minlength`, `type="email"` y `type="tel"`.
- CSS con Grid para la estructura de la página y Flexbox para el menú, las tarjetas y el pie de página.
- Diseño adaptable que empieza por el celular, con cambios en 768 px (tablet) y 1024 px (escritorio).
- Menú de tres rayitas en el celular, hecho solo con CSS.
- Fuente Source Sans 3 de Google Fonts.

## Cómo verlo en el computador

No necesita instalación. Descarga la carpeta completa y abre `index.html` en el navegador, o usa Live Server en VS Code.
